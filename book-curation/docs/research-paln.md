# 개인화 맞춤 AI 도서 큐레이션 시스템 연구 계획서

## 1. 연구 제목

**사용자 독서 행동 데이터를 활용한 개인화 맞춤 AI 도서 큐레이션 및 리랭킹 모델 연구**

---

## 2. 연구 배경 및 필요성

기존 도서 추천 서비스는 주로 인기 도서, 장르 분류, 검색 키워드, 단순 유사도 기반 추천에 의존하는 경우가 많다. 이러한 방식은 사용자의 실제 독서 목적, 관심 도서, 비관심 도서, 현재 읽고 있는 책, 읽은 책, 도서관 이용 가능성 등을 충분히 반영하기 어렵다.

본 프로젝트에서는 AI 도서 큐레이션 서비스를 통해 사용자가 자연어로 원하는 책을 질문하면, 약 10만 건의 도서 데이터를 기반으로 관련 도서를 추천하는 기능을 구현하였다. 또한 사용자 온보딩, 독서대, 관심/비관심 피드백, 나만의 도서관, 대출 가능 여부 조회 기능을 통해 개인화 추천에 활용할 수 있는 사용자 행동 데이터를 수집할 수 있는 구조를 마련하였다.

따라서 3주차 이후의 핵심 연구 목적은 단순 서비스 기능 확장이 아니라, 이미 구축된 서비스에서 수집되는 사용자 데이터를 기반으로 **개인화 맞춤 추천 품질을 개선하는 모델 및 리랭킹 구조를 설계하고 검증하는 것**이다.

---

## 3. 연구 목적

본 연구의 목적은 기존에 구현된 AI 도서 큐레이션 서비스를 기반으로, 사용자별 독서 성향과 행동 데이터를 반영하는 개인화 맞춤 추천 모델 및 리랭킹 구조를 연구하는 것이다.

세부 목적은 다음과 같다.

1. 사용자 온보딩 정보와 독서 행동 데이터를 추천 모델의 개인화 피처로 정의한다.
2. 관심 도서, 비관심 도서, 읽는 중 도서, 읽은 책 데이터를 활용한 사용자 취향 벡터를 설계한다.
3. 기존 벡터 검색 기반 추천 결과를 사용자 개인화 점수로 재정렬하는 리랭킹 방식을 연구한다.
4. 개인화 추천에 활용 가능한 데이터 파이프라인과 학습 데이터 구조를 설계한다.
5. SBERT 기반 사용자 취향 임베딩 또는 SASRec 기반 순차 추천 모델 적용 가능성을 검토한다.
6. 오프라인 평가 지표를 통해 개인화 리랭킹 적용 전후의 추천 품질을 비교한다.

## 5. 연구 문제

본 연구는 다음 연구 문제를 중심으로 진행한다.

### RQ1. 사용자 온보딩 데이터는 초기 추천 품질 개선에 유효한가?

신규 사용자의 경우 행동 데이터가 부족하므로 희망 장르, 독서 목적, 재미있게 읽은 책 등의 온보딩 정보를 활용해 초기 개인화 추천을 제공할 수 있는지 검토한다.

### RQ2. 관심/비관심 피드백은 추천 결과 리랭킹에 유효한가?

사용자가 추천 카드에서 누른 관심, 비관심 버튼을 각각 positive feedback, negative feedback으로 정의하고, 해당 피드백을 추천 후보 재정렬에 활용할 수 있는지 분석한다.

### RQ3. 읽는 중/읽은 책 데이터는 관심 도서보다 강한 취향 신호로 볼 수 있는가?

단순 관심 등록보다 실제 책읽기 등록이나 리뷰 완료가 더 강한 선호 신호인지 가중치 관점에서 검토한다.

### RQ4. 벡터 검색 결과에 개인화 점수를 결합한 리랭킹은 추천 품질을 개선하는가?

Qdrant에서 반환된 기본 유사도 점수에 사용자 취향 벡터, 장르 선호, 비관심 감점, 읽은 책 제외 등의 개인화 점수를 결합하여 추천 결과를 재정렬하는 방식을 연구한다.

### RQ5. SASRec 기반 순차 추천 모델은 본 프로젝트의 사용자 행동 데이터에 적용 가능한가?

사용자의 행동 시퀀스를 기반으로 다음 관심 도서를 예측하는 순차 추천 모델 적용 가능성을 검토한다.

## 7. 데이터 설계

### 7.1 도서 데이터

도서 데이터는 약 10만 건의 서지 데이터를 사용한다.

| 필드 | 설명 |
|---|---|
| isbn13 | 도서 식별자 |
| title | 도서명 |
| author | 저자 |
| publisher | 출판사 |
| description | 도서 설명 |
| category | 장르 또는 분류 |
| cover_url | 표지 이미지 |
| embedding | 도서 임베딩 벡터 |

Qdrant 컬렉션 구성은 다음과 같다.

```text
collection: books
count: 100000
vector size: 1024
distance: Cosine
```

---

### 7.2 사용자 행동 데이터

개인화 모델에 사용할 사용자 행동 데이터는 다음과 같다.

| 데이터 | 의미 | 추천 신호 |
|---|---|---|
| 희망 장르 | 온보딩에서 선택한 장르 | 초기 선호 |
| 독서 목적 | 사용자가 입력한 목적 | 텍스트 기반 선호 |
| 관심있는 책 | 사용자가 좋아요를 누른 책 | positive |
| 관심없는 책 | 사용자가 싫어요를 누른 책 | negative |
| 읽는 중 | 사용자가 읽기 시작한 책 | strong positive |
| 읽은 책 | 사용자가 리뷰까지 완료한 책 | strongest positive |
| 리뷰 평점 | 읽은 책에 대한 평가 | explicit rating |
| 대출 확인 | 실제 이용 의도 | weak positive |

## 8. 개인화 추천 모델 설계

### 8.1 기본 추천 구조

현재 기본 추천 구조는 다음과 같다.

```text
사용자 자연어 질의
  ↓
질의 임베딩 생성
  ↓
Qdrant 벡터 검색
  ↓
Top-K 도서 후보 반환
  ↓
LLM 응답 생성
  ↓
추천 카드 표시
```

3주차 이후 연구에서는 이 구조에 개인화 리랭킹 단계를 추가한다.

```text
Qdrant Top-K 후보
  ↓
사용자 개인화 점수 계산
  ↓
리랭킹
  ↓
최종 추천 결과 반환
```

---

### 8.2 사용자 취향 벡터

사용자의 긍정 피드백 도서 임베딩을 기반으로 positive preference vector를 생성한다.

```text
positive_vector =
  weighted_average(
    interested_books,
    reading_books,
    read_books
  )
```

가중치는 다음과 같이 설정할 수 있다.

| 행동 | 가중치 예시 |
|---|---:|
| 관심있는 책 | 1.0 |
| 읽는 중 | 2.0 |
| 읽은 책 | 3.0 |
| 리뷰 평점 5점 | 3.5 |
| 대출 확인 | 0.5 |

---

### 8.3 부정 취향 벡터

비관심 도서 임베딩을 기반으로 negative preference vector를 생성한다.

```text
negative_vector =
  average(not_interested_books)
```

최종 사용자 벡터는 다음과 같이 구성할 수 있다.

```text
user_vector =
  positive_vector - alpha * negative_vector
```

여기서 `alpha`는 부정 피드백 감점 강도를 의미한다.

---

### 8.4 리랭킹 점수 설계

최종 추천 점수는 다음과 같이 설계한다.

```text
final_score =
  base_vector_score
  + w1 * user_preference_score
  + w2 * category_match_score
  + w3 * availability_score
  - w4 * negative_similarity_score
  - w5 * already_read_penalty
```

각 항목의 의미는 다음과 같다.

| 점수 | 설명 |
|---|---|
| base_vector_score | Qdrant 검색 유사도 |
| user_preference_score | 사용자 취향 벡터와 후보 도서 벡터 유사도 |
| category_match_score | 희망 장르와 후보 도서 장르 일치도 |
| availability_score | 나만의 도서관 또는 주변 도서관 대출 가능성 |
| negative_similarity_score | 비관심 도서와의 유사도 |
| already_read_penalty | 이미 읽은 책 중복 추천 방지 |

---

### 8.5 규칙 기반 리랭킹

초기에는 학습 모델보다 규칙 기반 리랭킹을 우선 적용한다.

이유는 다음과 같다.

1. 사용자 데이터가 아직 충분하지 않다.
2. 6주 프로젝트 내 구현 가능성이 높다.
3. 가중치 조정만으로 추천 품질 변화를 빠르게 확인할 수 있다.
4. 이후 학습 모델의 baseline으로 활용 가능하다.

---

### 8.6 SBERT 기반 개인화

사용자 프로필 텍스트와 도서 텍스트를 같은 임베딩 공간에서 비교한다.

사용자 프로필 텍스트 예시:

```text
희망 장르: 소설, 인문, 자기계발
독서 목적: 위로받고 싶고 생각할 거리를 얻고 싶다
관심 도서: ...
읽은 책: ...
비관심 도서: ...
```

이를 SBERT 또는 기존 임베딩 모델로 벡터화하여 후보 도서와 유사도를 계산한다.

---

### 8.7 SASRec 기반 순차 추천

사용자의 행동 순서를 기반으로 다음 관심 도서를 예측한다.

행동 시퀀스 예시:

```text
INTERESTED(bookA)
READING(bookB)
READ(bookB)
NOT_INTERESTED(bookC)
INTERESTED(bookD)
```

SASRec 적용 검토 항목은 다음과 같다.

1. 사용자 수
2. 사용자별 행동 시퀀스 길이
3. 도서 item 수
4. 학습 가능한 positive/negative signal 수
5. GPU 메모리 요구량
6. cold-start 대응 방식

본 프로젝트에서는 SASRec을 즉시 상용 적용하기보다, 학습 데이터 구조와 PoC 가능성을 검토하는 수준으로 진행한다.

## 9. 리랭킹 실험 설계

### 9.1 Baseline

Baseline은 기존 Qdrant 벡터 검색 결과를 그대로 사용하는 방식이다.

```text
baseline = Qdrant vector similarity ranking
```

---

### 9.2 실험군 A: 장르 기반 리랭킹

희망 장르와 후보 도서 장르가 일치하면 가산점을 부여한다.

```text
score = base_score + category_bonus
```

---

### 9.3 실험군 B: 관심 도서 기반 리랭킹

사용자의 관심 도서 벡터와 후보 도서 벡터의 유사도를 반영한다.

```text
score = base_score + positive_similarity_bonus
```

---

### 9.4 실험군 C: 비관심 도서 감점

비관심 도서와 유사한 후보 도서에는 감점을 부여한다.

```text
score = base_score - negative_similarity_penalty
```

---

### 9.5 실험군 D: 통합 리랭킹

장르, 관심 도서, 비관심 도서, 읽은 책 제외, 대출 가능 여부를 모두 반영한다.

```text
score =
  base_score
  + user_preference_bonus
  + category_bonus
  + availability_bonus
  - negative_penalty
  - already_read_penalty
```

## 10. 평가 계획

### 10.1 오프라인 평가

수집된 사용자 행동 데이터를 train/test로 나누어 평가한다.

예시:

```text
과거 행동 데이터 → 사용자 프로필 생성
이후 관심/읽은 책 → 정답 데이터
추천 결과 Top-K와 비교
```

평가 지표는 다음과 같다.

| 지표 | 설명 |
|---|---|
| Precision@K | 추천 Top-K 중 실제 관심 도서 비율 |
| Recall@K | 실제 관심 도서 중 추천에 포함된 비율 |
| HitRate@K | 정답 도서가 Top-K 안에 하나라도 포함되는 비율 |
| NDCG@K | 순위 품질을 반영한 추천 성능 |
| MRR | 첫 관련 도서가 등장한 순위의 역수 |
| Coverage | 추천 가능한 도서 범위 |
| Diversity | 추천 결과 간 다양성 |

---

### 10.2 정성 평가

사용자 또는 팀원 평가를 통해 추천 결과의 품질을 확인한다.

평가 항목:

1. 추천 도서가 질의 의도와 맞는가?
2. 추천 도서가 사용자의 선호 장르와 맞는가?
3. 비관심 도서와 유사한 책이 줄었는가?
4. 이미 읽은 책이 반복 추천되지 않는가?
5. 추천 이유가 납득 가능한가?
6. 대출 가능 여부 정보가 실사용에 도움이 되는가?
