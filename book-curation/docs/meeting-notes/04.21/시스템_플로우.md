## 2. F-00: 인증 플로우 (v2.0 신규)

### 2-1. 소셜 로그인

```mermaid
flowchart TD
    START([소셜 로그인 선택]) --> PROVIDER{제공자 선택}
    PROVIDER -->|Google| G_AUTH["Google OAuth 2.0\nAuthorization Code Flow"]
    PROVIDER -->|Kakao| K_AUTH["Kakao OAuth 2.0\nAuthorization Code Flow"]

    G_AUTH --> CODE["Authorization Code 수신"]
    N_AUTH --> CODE
    K_AUTH --> CODE

    CODE --> EXCHANGE["서버: Code → Token 교환\nemail, name 수신"]
    EXCHANGE --> DB_CHECK{PostgreSQL\nemail로 유저 조회}

    DB_CHECK -->|기존 유저| JWT["JWT 발급\nAccess(30m) + Refresh(14d)"]
    DB_CHECK -->|신규 유저| CREATE["users INSERT\nauth_provider: google/kakao"]
    CREATE --> JWT

    JWT --> RESULT{신규 유저?}
    RESULT -->|Y| ONBOARD([온보딩 F-07 진입])
    RESULT -->|N| MAIN([메인 화면])
```

### 2-2. 자체 가입

```mermaid
flowchart TD
    START([자체 가입 선택]) --> INPUT["이메일 + 비밀번호 입력\n(비밀번호: 최소 8자, 영문+숫자)"]
    INPUT --> DUP{이메일 중복 확인}
    DUP -->|중복| ERR["❌ 이미 가입된 이메일이에요"]
    ERR --> INPUT
    DUP -->|사용 가능| HASH["비밀번호 bcrypt(cost=12) 해싱"]
```

### 2-3. 토큰 갱신

```mermaid
flowchart TD
    START(["API 호출\nAccess Token 만료"]) --> REFRESH["POST /auth/refresh\nRefresh Token (HttpOnly Cookie)"]

    DB_CHECK -->|유효| ROTATION["Refresh Rotation\n기존 토큰 revoked_at 기록\n새 Access(30m) + Refresh(14d) 발급"]

    DB_CHECK -->|만료| EXPIRED["401 REFRESH_EXPIRED"]

    DB_CHECK -->|이미 사용됨| REVOKED["⚠️ 탈취 의심!\n해당 유저 전체 세션 무효화"]
    REVOKED --> FORCE_RELOGIN(["401 REFRESH_REVOKED\n강제 재로그인"])
```
